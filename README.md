# ImmoWert

HTML Frontend zur überschlägigen Immobilienbewertung nach dem vereinfachten Ertragswertverfahren.

## Features

- Jahresreinertrag
- Bodenwertverzinsung
- Gebäudereinertrag
- Vervielfältiger
- Gebäudeertragswert
- Vorläufiger Ertragswert
- Kaufpreisvergleich
- Brutto- und Nettorendite

## Start

Einfach `index.html` im Browser öffnen.

Keine Abhängigkeiten.
